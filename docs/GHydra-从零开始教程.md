# GHydra 从零开始使用教程（GUI 面板版）

> 以 v1.0.2 实际界面为准。照着做，5 分钟从安装到加速生效。

---

## 0. GHydra 是什么

一个 GitHub 加速器：装在你自己电脑上，本地起一个代理（127.0.0.1:9801），用「IP 择优直连（通道 A）+ CDN 镜像（通道 B）」两条路让 GitHub 的网页、clone、Release 下载变快变稳。不联网时它不干活，不上传你的任何数据。

## 1. 安装（一次性）

1. 双击 `ghydra-windows-amd64-setup.exe`
2. 一路下一步（可改安装盘符），装完**开始菜单**会出现 GHydra
3. 已知问题（v1.0.2）：**桌面快捷方式可能没建、或双击闪退**——见第 10 节「故障排查」，一键修复

## 2. 启动面板

- 开始菜单 → **GHydra**（或桌面 GHydra 图标）
- 打开后窗口消失？看**屏幕右下角托盘**（小图标 ^ 展开找绿色水滴）——关窗口 = 缩到托盘，不是退出
- 托盘图标**左键单击** = 弹出/收起面板；**右键** = 菜单（打开面板 / 重启 daemon / 开机自启：切换 / 退出）

## 3. 第一次加速（核心 30 秒）——「加速」页

左侧导航点**加速**，最上面是「系统代理」大卡片：

```
○ 未接管            ← 当前状态：没接管，浏览器走默认网络
[一键加速（PAC）] [全局代理模式]
```

1. 点 **一键加速（PAC）**（推荐：只有 GitHub 相关流量走加速，其他网站不受影响）
2. 卡片变成 **● 已接管**，多出一个 **恢复直连（off）** 按钮——再点它就还原
3. 两个按钮的区别：
   - **一键加速（PAC）**：只加速 GitHub（推荐日常）
   - **全局代理模式**：所有 HTTP 流量都走 GHydra（非 GitHub 域名直连放行；想全走就选这个）

**验证生效**：浏览器开 `github.com`——能开且明显变快就成了。想看仪器数据回「状态」页点「立即体检」。

## 4. 「状态」页——它的心跳

| 卡片 | 含义 |
|---|---|
| 监听 127.0.0.1:9801 · v1.0.2 · 调度器 开 · 运行 xx s | 服务在跑，端口/版本/时长 |
| 连接 7 | 当前正在服务的连接数 |
| 通道 A open/closed | IP 直连通道的开关状态（接管后应为 open） |
| 通道 B | CDN 镜像通道（下载 Release 时用） |

下方**最近体检**：点「立即体检」跑一次六场景体检（clone/push/release/web/login/ssh），direct（裸连）对比 proxy（走 GHydra）。「通过」列 5/5 = 全通；如果哪行显示 **WARN** 是"能用但慢"，**FAIL** 才是真不通。

## 5. 下载 Release 文件——「下载」页

浏览器下 GitHub Release 慢/失败时：

1. 在 GitHub Release 页面**右键复制下载链接**（`https://github.com/.../releases/download/...`）
2. 粘贴到「新建下载」输入框 → 点 **开始**
3. GHydra 自动选通道（A=直连择优 / B=CDN 镜像），进度条 + 实时速度；下完在「最近任务」表里看记录

终端党等价命令：`ghydra get <url> -o 文件名`

## 6. Git clone / push 加速——「加速」页下半

**Git insteadOf**：点 **开启** 后，本机所有 `git clone/fetch/pull` 自动走加速（clone/fetch 走 B 通道），不用改任何仓库地址。点关闭还原。

**SSH 443**：公司网封了 22 端口导致 `git@github.com:...` 方式连不上时，点开启写入 ssh config 的 443 alias，`git clone git@github.com:owner/repo` 就能走 443 通道。

## 7. 「规则」页——自动维护，不用管

显示加速域名表（当前版本 / 生成时间 / 有效期 / 签名信任链状态）。**全自动更新、minisign 签名验证**，你只需要偶尔瞄一眼：「当前版本」徽章是绿色 = 官方签名规则在生效；显示「已过期（仍生效）」也不用慌，只是提醒，会自动换新。

## 8. 「设置」页

- **测试连接**：点一下显示 `✓ 已连接 v1.0.2 · xx ms`，说明面板和后台服务通信正常
- **API Token**：终端跑 `ghydra token` 获取后填入（一般不用动）
- **运行参数**：监听地址、规则源、体检周期（标注「重启生效」的改完要重启 daemon：托盘右键 → 重启 daemon）
- **自更新**：点「检查更新」→ 有新版点「下载并安装」→ 显示「✓ 已更新到 vX.Y」后按提示重启
- ⚠️ 已知问题（v1.0.2）：**普通（非管理员）终端里跑 `ghydra update` 会报 Access denied**——升级请用设置页自更新（管理员场景），或重新下载 setup.exe 覆盖安装。v1.0.3 修复

## 9. 停止 / 退出

| 想做什么 | 怎么做 |
|---|---|
| 暂时不用加速 | 加速页点「恢复直连（off）」或终端 `ghydra off` |
| 关窗口 | 点 X——缩到托盘，加速**继续**有效 |
| 彻底退出 | 托盘右键 → 退出（加速同时还原） |
| 后台服务卡死 | 托盘右键 → 重启 daemon |

## 10. 故障排查

**双击图标闪退 / 没反应**
v1.0.2 已知问题：图标没带 `gui` 参数。修复：右键快捷方式 → 目标末尾加 ` gui`；或开始菜单找 GHydra；或终端跑 `ghydra gui`。（v1.0.3 从安装器层面修复）

**面板显示「daemon 未连接」灰色**
后台服务停了：托盘右键 → **重启 daemon**。如果系统代理也没还原，终端跑 `ghydra off` 清干净再重来。

**开了加速反而上不了网**
`ghydra off` 立即还原直连；还不行就检查是不是装了其他代理工具（v2ray/Clash 等）在抢系统代理——两者别同时接管。

**更新失败 / Access is denied**
管理员身份打开终端再跑 `ghydra update`；或直接下载新 setup.exe 覆盖安装（设置会保留）。

**想确认一切正常**
终端跑 `ghydra doctor`——六场景体检报告，直连 vs 代理对比一目了然。
