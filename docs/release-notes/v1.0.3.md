# GHydra v1.0.3

安装与更新体验修复版：装完即见桌面图标、双击直达面板、普通权限也能自更新、面板不再"莫名消失"。

## 修复

### 安装器与启动（真机高频踩坑）

- **桌面快捷方式**：安装包此前只建开始菜单——现在桌面 + 开始菜单都建，均带 `gui` 启动参数
- **双击闪退根除**：官方构建的 `ghydra.exe` 无参数运行时直接进入桌面面板（此前打印命令行帮助后退出，双击表现为闪退）；命令行子命令用法完全不变
- **双安装安全**：卸载一份 GHydra 不再误删另一份的 Win+R/App Paths 注册（按安装目录归属条件删除）

### 自更新（v1.0.0→v1.0.1「Access is denied」三连败的真根因修复）

- **UAC 提权**：安装在 Program Files 等受保护目录时，普通权限运行 `ghydra update` 自动弹出 UAC 请求，确认后以管理员完成更新；取消 UAC 给出明确指引。已提权仍不可写的异常场景直接报错，绝不无限弹窗
- **staging 生命周期**：更新成功后立即清理暂存目录（此前三件套残留，与下次更新权限相撞形成恶性循环）；清理失败一律降级为警告，不再阻断更新主链
- GUI 面板更新失败时把"目录不可写"翻译成可操作的指引

### 托盘交互

- **面板唤起可预期**：托盘左键单击恒为唤起/置前（此前为切换语义——窗口可见时再点一次会隐藏，"面板莫名消失/点不回来"的来源）；隐藏面板仍走关闭按钮

## 升级方法

- **v1.0.2 及更早版本的用户**：请下载 `ghydra-windows-amd64-setup.exe` 覆盖安装（或**以管理员身份**打开终端运行 `ghydra update`）。提权门是 v1.0.3 新增代码——旧版本自身不含该逻辑，无法自动提权
- **v1.0.3 及以后版本**：直接 `ghydra update` 即可，普通权限运行会在需要时自动弹出 UAC（本版真机 dogfood 实证：普通权限 update → 提权交棒 → 管理员上下文完成下载/验签/交换/自检全链）
- 新用户：下载 `ghydra-windows-amd64-setup.exe` 安装，桌面双击即用

## 验收口径

真机 rc 演练：静默装 → 桌面 lnk 存在且带参 → 无参数启动直达面板 → 普通权限 update 触发 UAC（拒绝路径文案 / 同意路径全链成功）→ 双安装卸载不误删注册 → 托盘两次点击保持可见 → doctor/bench/on/off 复测协议零回归。
