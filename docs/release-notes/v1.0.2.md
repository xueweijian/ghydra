# GHydra v1.0.2

冷启动可靠性版本：首请求不再吃死 IP，off 生命周期闭环，doctor 分级可观测。

## 修复

### F3 冷启动竞速拨号（核心）

- **拨号帽 5s**：单候选最多烧 5 秒（原 7s；bench 实证好 IP 握手 45–105ms）。
- **竞速拨号**：无已验证上游时错峰并行拨多个候选（happy-eyeballs 式），首成者服务连接——单次 CONNECT 内自动换 IP 自愈，不再"失败即 502"。同域单飞门保证千并发不放大连接风暴。
- **预热**：`ghydra on` 接管即对域池并行预筛；last_good 与规则种子的验证空转 bug 修复（此前候选未验证直接进轮换）。
- **自更新修复**：`ghydra get` / 自更新等一次性进程改为同步预筛后再择路——v1.0.0 → v1.0.1 自更新三连败（确定性选中死 IP）的根因。
- **下载路径回灌**：A 通道下载的拨号/TLS 失败回灌调度池，死 IP 出局不再只靠用户流量。
- **度量**：`/api/status` 新增每域 `cold_first_ms` / `warm_p50_ms`；连接日志新增 `att=N`（>1 即本连接发生过竞速/重试自愈）。

### F12 off 生命周期

- CLI `ghydra off` 杀掉 daemon 后，GUI 面板带到前台明示「已停止」终态，不再做无提示僵尸壳。
- 托盘菜单新增「重启 daemon」（用户显式意图；off 保护语义不变——无显式意图的死亡绝不自动复活）。
- 面板残留横幅修复：断线后「已接管 / 接管系统代理 ✓」立即作废。
- CLI 文案区分面板场景：`on` 拒绝时提示「由 GUI 面板管理」；`off` 成功后提示面板不会自动重启。

### F5 doctor「可达但慢」分级

- 2xx 且速率 <100KB/s 或 TTFB >2s → `WARN`（class=slow），不计入失败：可用率口径更真实。

### 速赢包

- staging 清扫权限失败降级为告警，不再每条命令刷 `Access is denied` 并阻断崩溃恢复。
- release notes 由仓库内 `docs/release-notes/<tag>.md` 正式生成（本文件即首个）。

## 升级

已装 v1.0.0/v1.0.1 的用户：

```
ghydra update
```

或下载 `ghydra-windows-amd64-setup.exe` 静默安装（`/S`）。校验：`checksums.txt` + `checksums.txt.minisig`（minisign 公钥 `F0716070E4E793E7`）。

## 验收口径

- 冷启动 ≥10 次采样，首请求 P95 < 8s，30s 超时零出现（`/api/status` 冷/热字段可查）。
- GUI 常驻 + CLI off：≤3s 内面板终态提示，托盘「重启 daemon」可用。
- doctor 表 OK 列三态（OK/WARN/FAIL），WARN 不影响可用率。
