# M1 W4 真网冒烟（2026-09-13，有效批次）

网络状态：用户明确确认关闭魔法；shell 中所有 HTTP/HTTPS/ALL proxy 环境变量均为空。

## 直连对照

- 五个产品覆盖场景：**0/5**。
- 网页、登录、clone、push、Release 均约 10 秒超时。
- SSH `github.com:22` 超时；`ssh.github.com:443` TCP 可达。
- `api.github.com/meta` 可达，证明是选择性主机/端口问题，不是整机断网。

## GHydra 代理通道（TLS SNI 预筛修复后）

- 本地 CONNECT：`127.0.0.1:19802`。
- 五个产品覆盖场景：**5/5**；SSH 观测：**2/2**。
- web/login/clone/push/release：HTTP 200/200/200/401/200。
- 最终择优：`20.205.243.166:443`；网页收到约 126KB，TLS/HTTP 完整通过。
- `185.199.x` 候选仅 TCP 可达但 TLS ClientHello 后无响应；修复前它们被误标 Active，导致代理五场景全部超时。
- 修复后 Preflight 改为按目标 host 做 TLS SNI 握手，死 IP 全部进入 Cooldown/Quarantine；代理通道恢复 5/5。
- SSH `ssh.github.com:443` 已改为 M1 放行（不误当 HTTPS 加速）；池枯竭补充地址统一规范化为 `IP:443`。

## 结论

这是第一批有效的“关闭魔法”真网证据。它同时验证了 W4 探针/直连对照、W2 调度器的 TLS 级预筛、故障切换和五场景恢复。该结果只代表当前网络窗口，不等于 7 天 SLA；Windows 主力机 `ghydra on/off` + 注册表 PAC 真机验收仍是 dogfooding 入口。
