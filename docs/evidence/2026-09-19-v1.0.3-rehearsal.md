### update UAC 提权（三路径真机验证）

- 构造：icacls deny lx:(W) 于 F 安装目录 → 普通权限 `ghydra update`
- **Relaunched 路径**：输出「安装目录需要管理员权限——已弹出 UAC 请求…」+ ShellExecute runas 实际执行（本机 ConsentPromptBehaviorAdmin=0 静默提权，无递归、0.59s 干净退出）✅
- **Guard Fail 路径**（GHYDRA_ELEVATED=1 + 不可写）：「更新中止: 安装目录 …不可写（已尝试提权仍失败）——请以管理员身份运行，或从 Release 下载安装包覆盖升级」✅
- ACL 测试后恢复（deny 撤销、目录可写复验）✅
- **提权子进程成功 apply 全链**：留给正式发布 dogfood（C 盘 v1.0.2 普通权限 update → v1.0.3）
